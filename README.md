# 직구 계산기

아마존 상품 페이지 가격 아래에 원화 가격, 면세 여부, 예상 관부가세를 바로 보여주는 크롬 확장이에요.

- **원화 가격**: 유럽중앙은행 기준 환율로 바꿔서 보여줘요.
- **면세 여부**: 한도까지 얼마 남았는지, 넘었는지 알려줘요.
- **예상 관부가세**: 한도를 넘으면 품목별 관세와 부가세 10%를 더한 합계를 보여줘요.
- **사이즈·색상 변경 반영**: 옵션을 바꿔 가격이 달라지면 다시 계산해요.

지원 사이트: `amazon.com`, `amazon.co.jp`

## 면세 기준

| 경우 | 한도 |
| --- | --- |
| 미국 발송 + 특송 + 목록통관 품목 | 200달러 이하 |
| 미국 외 국가, 우편 배송, 식품·영양제·기능성 화장품 | 150달러 이하 |

한도를 넘으면 초과분이 아니라 **전체 금액**에 관세와 부가세가 붙어요.

## 계산에서 빠진 것

- 국제 배송비 (상품 페이지에서는 알 수 없어요)
- 관세청 고시 환율과의 차이 (주 단위로 고시돼서 조금 달라요)
- 개별소비세, FTA 원산지 혜택, 합산과세
- 세율은 품목별 대표값이에요. 정확한 금액은 [관세청 유니패스](https://unipass.customs.go.kr)에서 확인하세요.

## 직접 설치해 보기

```bash
pnpm install
pnpm build
```

1. 크롬에서 `chrome://extensions` 를 열어요.
2. 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `.output/chrome-mv3` 폴더를 골라요.
4. 아마존 상품 페이지를 열면 가격 아래에 배지가 떠요.

## 개발

```bash
pnpm dev       # 확장이 깔린 크롬이 열리고, 코드를 고치면 바로 다시 로드돼요
pnpm test      # 계산·가격 읽기 단위 테스트
pnpm compile   # 타입 검사
pnpm e2e       # 빌드된 확장을 크롬에 깔고 실제 아마존 페이지에서 배지 확인 (먼저 pnpm build)
pnpm zip       # 크롬 웹스토어에 올릴 zip 만들기
```

처음 `pnpm e2e` 를 돌리기 전에 `pnpm exec playwright install chromium` 이 필요해요.

## 구조

```
lib/
  customs.ts      면세 한도·관부가세 계산 (순수 함수)
  categories.ts   품목별 관세율, 아마존 분류 → 품목 추정
  price.ts        "$1,234.56" 같은 가격 문구 읽기
  amazon.ts       아마존 페이지에서 가격·분류·예치금 문구 읽기
  rates.ts        환율 받기 (6시간 캐시, 실패하면 이전 값 사용)
  settings.ts     저장 설정 (켜기/끄기, 배송 방식, 기본 품목)
entrypoints/
  amazon.content/ 가격 아래에 붙는 배지
  popup/          툴바 아이콘 설정 창
  background.ts   환율을 받아 배지에 전달
```
